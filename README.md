# 🌍 Global Economic Analysis Using Excel

An Excel-based data analysis project using **World Bank economic data from 2010–2025**.

The project focuses on cleaning, analyzing, and visualizing economic indicators across 10 countries using Microsoft Excel.

## 📊 Project Overview

This project transforms raw World Bank data into an interactive analytical dashboard.

The workflow includes:

**Raw Data → Power Query → Excel Formulas → PivotTables → Charts → Interactive Dashboard**

## 🌐 Dataset

**Source:** World Bank

**Period:** 2010–2025
**Countries:** 10
**Economic Indicators:** 10

The dataset includes indicators related to economic growth, inflation, GDP, and other economic measures.

## 🛠️ Tools & Techniques

* Microsoft Excel
* Power Query
* SUMIFS
* COUNTIFS
* INDEX + MATCH
* LOOKUP
* PivotTables
* PivotCharts
* Slicers
* Dashboard Design

> **Note:** The Excel version used for this project did not support XLOOKUP, so INDEX + MATCH was used as a compatible alternative.

## 🔎 Analysis Performed

The project includes analysis of:

* Average GDP growth across countries
* GDP growth trends from 2010–2025
* GDP by country for 2025
* Average inflation across countries
* GDP growth compared with inflation
* Pakistan's economic indicators over time
* Years with GDP growth above 5%

## 📈 Dashboard

The final dashboard provides an interactive overview of the analysis.

It includes:

* Countries analyzed
* Years covered
* Indicators
* Average GDP Growth by Country
* GDP Growth Trend
* GDP by Country — 2025
* Average GDP Growth vs Inflation
* Country slicer for interactive filtering

## 🧹 Data Preparation

The original World Bank dataset was provided in a wide format with separate columns for each year.

Using **Power Query**, the year columns were unpivoted and transformed into a structured format:

**Country → Indicator → Year → Value**

This made the dataset easier to analyze using formulas and PivotTables.
